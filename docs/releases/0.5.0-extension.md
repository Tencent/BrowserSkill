BrowserSkill Extension 0.5.0 improves the browser observations agents use, supports optional local pairing, and fixes shared-control and navigation regressions. Pair it with CLI/daemon 0.5.0.

### Added

- **Optional local pairing.** Connection settings can verify the daemon and browser identities and recover interrupted pairing. The CLI supports replacing or revoking a paired device.
- **Richer observations.** Unlabeled inputs can use nearby captions, native selects show their options, and runs of read-only table rows take fewer lines. Native select can match a unique visible option label.
- **Safer target selection.** The extension filters visually hidden instructions from observations while preserving accessible labels. It checks whether a virtualized list has reused the target row before dispatching an action.
- **Collapsible shared-control panel.** Minimize the in-page panel to the edge of the tab while a task is active.

### Changed

- When visible text is the only change and the previous observation can be reused, shared-control sync can return a text patch. The extension also reuses recent accessibility data and reduces repeated checks during targeted actions.
- The extension releases idle debugger connections and reattaches when a browser task needs them. Open dialogs and active downloads keep their connections.
- Connection settings stay visible in the popup. The pairing control shows the current verification state and offers instructions for pairing or continuing with an unpaired local connection.

### Fixed

- Background fills deliver focus before editing and report page formatting. Sensitive values stay redacted.
- Navigation waits follow scheduled loads and complete when Chromium restores a page from its back/forward cache.
- Borrowed blank tabs can navigate or return. Hidden, unresponsive child frames can be reported separately so eligible page actions can proceed.
- Native input remains correctly attributed after Chromium clock drift, and the control panel preserves click passthrough during status refreshes.
- Recording captures native select changes in open shadow roots and better recognizes form controls and long button or link names.

### Upgrade

1. Finish active browser tasks and update the [CLI/daemon to 0.5.0](https://github.com/Tencent/BrowserSkill/releases/tag/cli-v0.5.0).
2. Install extension 0.5.0 from the store or use the ZIP attached to this release. Store availability follows each store's review.
3. Run `bsk doctor` to verify the connection. To pair a local browser, run `bsk daemon pair` and paste the link into the extension's connection settings.
