BrowserSkill CLI 0.5.0 simplifies session management and adds guarded batch actions, reusable recipes, and bounded DOM reads. Use it with extension 0.5.0 for the new observation and interaction features.

### Added

- `bsk open`, `bsk sync`, and `bsk close` manage a browser session for the current caller. Use `--scope <name>` to isolate parallel tasks. Sync returns short context and observation IDs for subsequent actions.
- `bsk plan` runs a sequence of decided actions and stops on the first incomplete step. `bsk recipe` saves and replays verified workflows, with approval for supported reversible steps and a hold when a previous run's outcome is uncertain. Plan is available in MCP and DSH, and recipe tools are opt-in.
- `bsk read` samples bounded DOM fields such as text, attributes, and form state on changing pages. MCP and DSH expose the same read operation. Scripts can declare what they depend on for a narrower pre-action check.
- The daemon records pending browser actions in a local intent ledger. If an action's effect is uncertain, the ledger holds subsequent writes on that tab until reconciliation. Use `bsk sync` to inspect current state and `bsk ledger status` to check the hold.
- Local pairing verifies the browser and daemon identities and supports credential rotation, recovery, and revocation. Pairing remains optional for local connections. Skill installation also supports Qoder and Qoder CN.

### Changed

- The CLI can apply a text-only observation patch to its exact saved baseline and write the merged observation for offline inspection with `bsk view`. The daemon and extension also reduce repeated work during synchronization and targeted actions.
- Native select accepts unique visible option labels. Fill reports when the page reformats the value and redacts the resulting value for sensitive fields.
- The packaged skill uses the new session commands and documents how to recover when an action's effect is uncertain. DSH documentation covers tool access through `run_code` in PTC mode.

### Fixed

- Text waits in `bsk open` and `bsk sync` evaluate the full observation even when the latest response is a delta or has a token limit.
- `bsk get-html --json --out <file>` writes HTML to the file and returns its path and size in JSON.
- Recording retains its captured steps through session cleanup and better recognizes form controls, shadow DOM selects, and controls whose positions change.
- Native input calibrates Chromium's clock to reduce false human-intervention events. Navigation waits handle pending navigation and back/forward cache restores.

### Upgrade

1. Finish active browser tasks and run `bsk update --yes`. If a supervisor manages your daemon, restart it through the supervisor.
2. Install [extension 0.5.0](https://github.com/Tencent/BrowserSkill/releases/tag/ext-v0.5.0) and update the DSH plugin to 0.5.0 if you use it.
3. Reload your browser-skill instructions. Restart your MCP client or DSH profile if it still uses the previous version.
4. Check the connection with `bsk --version`, `bsk status`, and `bsk doctor`.
