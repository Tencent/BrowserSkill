BrowserSkill CLI 0.4.2 adds MCP access and more reliable updates, cancellation, and action outcomes. Use it with extension 0.4.2 for the browser-side fixes below.

### Added

- **MCP server:** `bsk mcp` exposes BrowserSkill over stdio through the existing daemon and extension. `bsk install-skill --mcp` configures Codex, Claude Code, or Cursor. The initial adapter covers its tool schemas; file transfers, recording, and full-page screenshot export remain available through the CLI or DSH plugin.
- **Controller identity:** session startup accepts an agent name, project, and color, shown in the extension's shared-control overlay and session metadata.
- **Date and time inputs:** `fill` supports `date`, `time`, `datetime-local`, `month`, and `week`, with format and min/max validation.

### Changed

- CLI and daemon updates prefer the official website's domestic download source and fall back to GitHub on download or verification failures. Archive fallback stays on the selected version and retains SHA256 verification. Explicit manifest overrides continue to use only the configured source.
- Borrowed tabs return relative to their original neighbors, with improved pinned-tab and group restoration. Eligible requests can automatically borrow a tab when borrow confirmation is disabled.
- Shared control now waits for two seconds of quiet after the person's last completed action, up from 650 ms.

### Fixed

- Timed-out page actions cancel and await bounded cleanup. Errors preserve execution phase, effect state, and operation identity. Missing receipts remain explicitly uncertain; CLI and MCP guidance asks callers to inspect the application result before choosing another action.
- Cancellation arriving before daemon RPC registration is retried within a shared two-second confirmation/response budget, reducing screenshots that keep a session busy after the caller stops.
- Windows remote pairing, credential rotation, and revocation retry authorization snapshot replacement when concurrent readers cause `Access is denied`.
- Shared-control sync recovers missing frame collectors, reports failed child frames safely, preserves human holds, and retries transient coverage failures within its deadline.
- Recovery guidance identifies the sync reply's top-level `observation_id`. Borrow guidance explains closed tabs and unavailable confirmation UI.
- DSH fill/select values beginning with `-` are passed as values instead of being parsed as CLI options.

### Coordinated extension fixes

- Restore legacy `mousewheel` handlers, including Bilibili player volume controls, even when no BrowserSkill task is active.
- Avoid repeated page reloads caused by enabling console capture before it is requested.
- Prevent truncated emoji text from invalidating an entire daemon reply and leaving commands waiting until timeout.
- Let automated clicks reach page controls beneath the shared-control toolbar; preserve successful Enter-triggered navigation receipts.
- Keep scrolling, ineffective keys, and focus alone from unnecessarily taking control; release completed/cancelled gestures and composition holds correctly.
- Preserve main-document target actions across unrelated iframe refreshes, recheck selectors after node replacement, and associate repeated action labels with their own DOM containers.
- Verify actual window and viewport sizes after resizing, and refresh shared-control observations.
- Extend sensitive-field redaction across shared-control state, expectation failures, extraction, recording, and saved HTML debug evidence; recognize compound autocomplete tokens and keep recognized password fields masked after reveal. Redact vendor credential headers in debug evidence.

### Upgrade

1. Finish active browser tasks and run `bsk update --yes`. Restart foreground or supervisor-managed daemons in their owning terminal or process manager; after replacing the executable with an installer, run `bsk daemon restart`.
2. Install [extension 0.4.2](https://github.com/Tencent/BrowserSkill/releases/tag/ext-v0.4.2) and update the DSH plugin to 0.4.2. Store review may delay availability.
3. Reload the browser-skill instructions. DSH users should restart the profile and invoke `/browser-skill` again. Restart MCP clients after adding their configuration.
4. Check `bsk --version`, `bsk status`, and `bsk doctor`.
