BrowserSkill Extension 0.4.2 fixes everyday page interaction regressions and improves shared-control reliability, action outcomes, and sensitive-data protection. Pair it with CLI/daemon 0.4.2.

### Added

- **Controller identity:** browser overlays display the agent name, project, session ID, and color supplied by the CLI or DSH client.
- **Date and time inputs:** fill native date, time, datetime-local, month, and week fields, including background-tab handling and format/min/max validation.

### Changed

- Scrolling, ineffective keys, and focusing a text field alone no longer unnecessarily take control from the Agent. Real clicks, keyboard activation, and actual edits still yield to the person. Pending gestures pause dispatch without revoking the current context; coordinate input waits for scrolling to settle.
- Shared control waits for two seconds of quiet after the person's last completed action, up from 650 ms. Completed/cancelled gestures, input-method composition, and native select interactions release their holds correctly.
- Borrowed tabs return relative to their original neighbors, with improved pinned-tab and group restoration. Eligible requests support automatic borrowing when borrow confirmation is disabled.
- The extension restores the `tabGroups` permission to read and restore borrowed tabs' original groups.

### Fixed

- **Broken wheel interactions:** restore legacy `mousewheel` handlers, such as Bilibili's player volume control, which could stop working even without an active BrowserSkill task.
- **Repeated page reloads:** enable console capture only when requested, avoiding anti-debugging reload loops on affected sites.
- **Unexpected command timeouts:** replace lone Unicode surrogates left by truncated emoji so the daemon no longer discards the entire reply.
- **Toolbar-blocked clicks:** the shared-control toolbar and its children yield pointer hits during automated clicks, including page actions beneath the lower-right corner, then become interactive again.
- **Enter navigation receipts:** dispatch Enter keydown and text together, retain completed link/form navigation outcomes, and avoid sending a separate character event into the new document.
- **Timeout cleanup and diagnostics:** cancelled actions retain execution phase and effect-state information; missing completion receipts remain explicitly uncertain.
- **Repeated action labels:** use each action's own DOM container for context, including labels after the button, instead of mixing text from adjacent records or other frames.
- **Dynamic element waits:** requery selectors when matched nodes are replaced, avoiding false hidden/detached success while a replacement remains visible.
- **Unrelated iframe refreshes:** keep main-document target actions valid when a carousel, video, or ad iframe refreshes. Frame-targeted and strict-observation actions still require a fresh sync after document changes.
- **Frame synchronization:** repair missing collectors, report failed frames safely, preserve human holds, and bound retries for temporary coverage failures.
- **Window resizing:** verify resulting bounds and the target tab's viewport rather than echoing the requested size, and refresh subsequent observations.
- **Sensitive fields:** extend redaction for passwords, one-time codes, and payment-card fields across shared-control state, expectation failures, extraction, recording, and saved HTML debug evidence. Match compound autocomplete tokens, preserve masking for recognized password fields after reveal, and redact vendor credential headers.

### Upgrade

1. Finish active browser tasks and update the [CLI/daemon to 0.4.2](https://github.com/Tencent/BrowserSkill/releases/tag/cli-v0.4.2).
2. Install extension 0.4.2 from the store or the ZIP attached to this release. Store submissions require review; check the installed version.
3. Update the DSH plugin to 0.4.2 and reload browser-skill instructions. Check `bsk status` and `bsk doctor`.

CLI 0.4.2 also adds `bsk mcp` for MCP clients and domestic update downloads with GitHub fallback. See the CLI release for setup and daemon-side changes.
