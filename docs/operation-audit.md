# 操作审计

操作审计帮助个人用户按任务回看 BrowserSkill 代为执行的操作。默认关闭，记录保存在运行本地服务的电脑上，不上传到远端。

## 使用入口

扩展弹窗右上角的小火箭 → 快捷功能 → **操作审计**。该入口与操作录制并列，描述为「操作审计介绍」。

- 关闭时，子页面只显示审计开关。
- 开启后显示最近 5 次任务，包括执行中的任务，并提供「查看全部任务」。
- 点击任务，在独立扩展标签页查看任务摘要、时间线、操作状态和可展开的技术详情；页面每 3 秒更新一次。
- 全部任务页提供分批加载、实际保存目录和「打开文件夹」。详情页支持导出 JSON，以及确认后删除已结束任务。执行中的任务不能删除。
- 本地服务离线、版本不支持或存储故障时显示明确提示，不能把失败显示成「暂无任务」。离线时仍可保存开关偏好，下次连接时生效。

## 任务与结果的含义

首版以一个 BrowserSkill session 为一个任务。每份审计记录使用独立 UUID，即使短 session ID 被重复使用，也不会串联到旧任务。

可在启动时命名：

```sh
bsk session start --name "整理本周待办"
```

未命名时，显示网站与任务开始时间。任务状态为「执行中」「已结束」「已中断」，不代表用户的业务目标已完成。操作状态表示工具返回成功、失败、取消或结果未知；超时、缺少返回值以及中途停录均不能推断成成功。脚本内部执行的多个动作只能作为一次脚本调用记录，不能还原为逐次点击。

中途开启只记录之后的操作，并标注「部分记录」。关闭开关会停止收集新操作，保留已有记录，且不停止任务；再次开启会在同一任务中标出暂停和恢复位置。已开始记录的任务在关闭开关后仍会写入最终生命周期状态，以免长期显示执行中。服务重启或浏览器断开后，无法证明正常结束的任务显示为已中断。

## 保存位置与保留期限

| 系统 | 默认目录 |
| --- | --- |
| macOS | `/Users/<用户名>/.bsk/audit/` |
| Windows | `C:\Users\<用户名>\.bsk\audit\` |
| Linux | `/home/<用户名>/.bsk/audit/` |

设置 `BSK_HOME` 时保存到该目录下的 `audit` 子目录。以扩展页展示的实际路径为准。开关偏好保存在浏览器配置文件的 `chrome.storage.local` 中；审计正文由本地服务保存，不占用扩展存储配额。卸载扩展不会删除这些本地文件。

每个任务对应一个 `<开始记录时间戳>-<UUID>.jsonl` 文件，包含逐行追加的事件。macOS/Linux 上目录权限为 `0700`、文件为 `0600`；Windows 使用用户目录继承的权限。保留最近 30 天已结束的任务；服务加载记录、开启审计、创建任务或查询列表时清理过期记录，执行中或仍有待返回调用的任务不会自动删除。导出的文件由用户自行保管，不参与自动清理。

单任务文件上限约 16 MiB。写入失败时不派发该次尚未开始的操作，并提示检查审计页或关闭审计；操作已派发后若返回记录写入失败，则保留可用记录并提示存储异常。恢复读取时忽略最后一条未写完的事件，不能将未知结果推定为成功。本功能用于个人回顾，不提供防篡改或不可抵赖保证。

## 记录范围与隐私

只写入允许的元数据：任务标识、时间、工具类型、标签页编号、网站来源、缓存中的元素名称、操作状态、错误码以及少量数量信息。页面来源只保留协议、域名和端口；导航目标与操作前所在页面分别保存。

不保存截图、页面正文、完整 DOM、输入值、脚本、完整选择器、原始错误消息、上传文件内容或本地文件路径。输入项统一标记为已隐藏；元素名称和任务名截断并进行基础脱敏，仍建议避免在任务名中填写敏感信息。导出仅使用已保存的脱敏数据。

审计接口仅由扩展页面经后台服务访问，网页内容脚本不能调用。服务按已连接的浏览器实例隔离列表、详情和删除操作，不采用请求参数中的浏览器身份。它沿用现有本地连接的信任模型，不构成对同一系统账户下恶意进程的安全边界。

## 接口概要

握手可携带 `audit_enabled`，服务返回可选能力 `audit_version: 1` 与 `audit_ready`。旧版本扩展保持默认关闭；新扩展连接旧服务时显示不支持提示。

扩展侧请求 `audit.request` 支持 `configure`、`list`、`get`、`delete`、`open_directory`。列表使用 `offset`/`limit`，每批最多 100 个任务；详情每批最多 500 个事件。服务内部生成操作关联 ID，扩展通过 `audit.context` 补充受控标签页上下文，CLI 传入的同名关联字段会被丢弃。

事件包括 `started`、`named`、`operation_started`、`context`、`operation_finished`、`paused`、`resumed`、`user_interrupt`、`ended`。时间线按操作 ID 合并开始、上下文和结果事件，保留重复执行与重试。导出包含 `version`、`run` 和 `events`，导出进行中的任务时以开始导出的事件数为边界。
