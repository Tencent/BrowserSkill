# BrowserSkill 隐私政策

**最后更新：** 2026 年 9 月 23 日

本隐私政策说明 **BrowserSkill** 浏览器扩展（下称"本扩展"）在您安装和使用过程中如何处理信息。BrowserSkill 作为开源项目 [BrowserSkill](https://github.com/Tencent/BrowserSkill) 的一部分发布，源代码完全公开，可供审计。

如有任何疑问，请在项目仓库中提交 issue 与我们联系。

---

## 1. BrowserSkill 的用途

BrowserSkill 让用户指定的 AI 助手通过 `bsk` 命令行工具操作 Chromium 浏览器。默认连接同一台计算机上的守护进程；用户也可以主动配对到运行 bsk 的服务器或兼容的第三方网关。远程模式会向用户选择的服务器发送自动化数据。本扩展不会自行调用 AI 提供商。

## 2. 单一用途

本扩展向用户选择的 BrowserSkill 守护进程或兼容网关提供浏览器自动化能力，让 AI 助手按用户要求操作网页。本地连接使用回环 WebSocket，远程连接使用经过鉴权的 WSS。当前版本的远程模式不支持上传和下载。

可选的网站调试功能让用户或其 Agent 在同一项已授权的浏览器任务中检查请求、页面行为和性能，并将调试历史保存在浏览器本地，供后续查看。

## 3. 本扩展会访问的数据

根据用户（通过其 AI 助手）发送给所选守护进程或网关的指令，以及用户在扩展中主动开启的功能，本扩展可能会在**用户本地设备上**访问以下数据：

| 类别 | 访问内容 | 用途 |
|---|---|---|
| **网页内容** | "代理窗口"中的受控页面、按浏览器确认设置借用的标签页，或用户主动使用快捷功能选择的页面中的 DOM、可访问性树、HTML 和截图。 | 用于读取页面、定位元素、验证执行结果和生成用户请求的截图。 |
| **AI 助手模拟的用户输入** | 通过 Chrome DevTools Protocol（CDP）派发的鼠标点击、键盘输入、表单值。 | 用于执行用户委托给 AI 助手的自动化操作。 |
| **网站调试数据** | 采集期间选定标签页的请求 URL、方法、请求头、可获取的请求与响应正文、状态、耗时、错误及相关网络元数据；控制台消息；Agent 操作与受支持的手动输入、点击、提交和导航事件；有数量及长度限制的可见页面文本、表单字段值、页面状态和性能数据。还会记录已配置的 HTTP 规则和请求重放结果。 | 用于检查和复现网站行为，将操作与请求及页面变化关联，分析性能，以及查看或导出调试历史。 |
| **标签页与窗口元数据** | 标签页 ID、URL、标题和窗口 ID，包括为选择借用目标而列出的用户标签页。 | 用于将自动化指令发送到正确的标签页/窗口。 |
| **扩展本地存储** | 一个随机生成的 8 位十六进制实例 ID、可选的用户自定义标签、功能偏好（包括审计开关），以及可选的远程端点和设备凭据。 | 用于识别此浏览器实例并恢复用户设置。 |
| **Agent 请求的文件传输** | 用户明确提供给 `bsk upload` 的本地文件，以及单次 `bsk download` 操作产生的文件。 | 用于将任务文件附加到网页，或将浏览器生成的下载交给发起请求的本地 Agent。 |
| **系统通知** | 当 AI 助手请求"借用"用户已有标签页时显示系统通知的权限。 | 用于在浏览器借用确认开启时获取用户对该标签页的同意。 |

## 4. 数据收集边界

- 自动化结果仅发送到用户选择的守护进程或网关。BrowserSkill 作者不接收遥测数据，也不提供必须使用的中间托管服务。
- 本扩展不会自行调用 LLM、AI 或云 API，不包含 AI 提供商的 API 密钥。
- 本扩展不会枚举浏览器的浏览历史数据库、书签、保存的密码或自动填充数据库。网站调试会单独记录采集期间选定标签页的活动，这些调试历史与浏览器的浏览历史数据库相互独立。下载处理只针对本地 `bsk download` 指令发起的下载。
- 网站调试仅在用户或其 Agent 明确发起时开始。每项任务的单次采集只针对一个由该任务创建或借用的标签页，包括其 frame 的网络数据。仅打开标签页或将其移入代理窗口不会授予采集权限。采集期间，选定页面中受支持的手动操作与 Agent 操作都会被记录。
- 停止采集、归还或关闭目标标签页、结束任务或断开连接，会停止收集新数据，但不会删除已保存的调试历史。浏览器或扩展重启后，未完成的采集会以中断状态恢复，不会自动继续采集。
- 自动化使用现有浏览器配置。受控页面可能包含个人数据和已登录的网站会话；配对服务器后，其 Agent 可以操作这些页面。
- 本扩展不包含分析统计、广告、指纹识别或跨网站跟踪系统，也不出售用户数据。

## 5. 权限使用说明

本扩展申请以下 Chrome 权限，每一项都仅用于上述单一用途：

- **`debugger`** —— 将 Chrome DevTools Protocol 附加到选定的自动化或用户主动截图的标签页，使 BrowserSkill 能够观察、操作和截取这些页面。在明确开启的网站调试期间，也用于读取网络请求／响应头及正文、控制台和性能数据，观察页面操作及字段值，以及执行明确配置的任务内 HTTP 规则和请求重放。
- **`activeTab`** —— 用户调用扩展时，临时访问当前标签页，用于用户主动发起的快捷功能。
- **`scripting`** —— 选定页面缺少长截图辅助脚本时补充注入，例如扩展重新加载后。
- **`webNavigation`** —— 跟踪页面导航和 frame，让截图、录制与人工协助完成检查对应到正确的文档。
- **`tabs`** —— 在代理窗口内查询、创建、关闭标签页；读取标签页元数据。
- **`windows`** —— 创建并管理独立的代理窗口，将助手的活动与用户的日常浏览隔离开。
- **`alarms`** —— 周期性唤醒 service worker，保持所选 WebSocket 连接并续期远程授权。
- **`idle`** —— 检测设备从空闲或锁定状态恢复，以便及时重新建立所选 WebSocket 连接；不保存或传输空闲状态数据。
- **`notifications`** —— 浏览器借用确认开启时，通过系统通知请求用户授权借用已有标签页。
- **`downloads`** —— 关联和处理当前 `bsk download` 命令发起的单次下载。如果已认领的传输失败，BrowserSkill 会取消进行中的下载，或删除已完成的浏览器临时文件；不会枚举下载历史或更改未认领的下载。
- **`storage`** —— 在 `chrome.storage.local` 中保存随机实例 ID、可选标签及功能偏好。远程凭据和网站调试历史与这些设置分开，保存在扩展来源的 IndexedDB 中。
- **主机权限 `<all_urls>`** —— 在助手控制的页面上注入状态浮层（提示"代理已激活"），并支持用户引导助手访问任意网站。远程连接也使用此权限访问用户选择的端点。远程页面内容访问要求标签页由任务创建或明确借用。

## 6. 数据流向

本地模式连接回环地址上的守护进程，默认端口为 **52800**。远程模式向用户主动选择的服务端点发送 HTTPS 配对和续期请求，并通过经过鉴权的 WSS 传输自动化数据。明文 HTTP/WS 仅允许用于回环地址开发。配对凭据会在发出网络请求前从 URL 中移除。

所选服务器可以接收任务结果，包括请求的页面内容、截图、录制轨迹、标签页元数据，以及按指令请求的网站调试数据；调试数据可包含已保留的请求／响应头及正文、控制台消息和字段值。标签页列表可包含用户标签页的标题和 URL，以便选择借用目标。Agent 或网关运营者可能依据其自身政策保存或转发结果。远程模式开启的操作审计保存在守护进程所在服务器上，而非浏览器所在计算机。BrowserSkill 不要求使用中间托管服务。

网站调试历史始终保存在当前浏览器配置中，包括连接远程守护进程时；无需连接守护进程，也可在扩展的历史页面查看。原任务的 Agent 可在任务仍有权访问目标标签页时请求已保留的数据；任务结束或标签页归还后，该 Agent 的访问权限会撤销，用户仍可查看或导出本地历史。保存历史不会自动将整个历史库上传到所选服务器。导出的 JSON 文件包含已保留的调试数据，用户可自行分享。

在采集期间，用户或 Agent 明确配置的 HTTP 规则可以阻止或修改请求，或提供模拟响应。请求重放会向与原请求及当前页面相同的 HTTP(S) 来源发送一次新请求，使用页面当前的浏览器会话，包括由浏览器提供的 Cookie。重放可将指定的请求头和正文发送给该网站，并改变其服务端数据。仅打开历史或读取调试数据不会重放请求。

## 7. 数据保留

- 实例 ID、可选标签和功能偏好会保存在 `chrome.storage.local` 中，直到用户卸载本扩展或清除扩展存储。
- 网站调试以外的页面内容、截图、DOM 快照等观察数据，会作为对指令的响应返回给所选守护进程或网关；录制或截图导出等操作可在扩展中暂存数据，直到相关操作结束或结果释放。网站调试数据遵循下述独立的历史保留规则。
- 网站调试在采集期间及停止时，将经过脱敏处理的数据保存到扩展来源的 IndexedDB。已停止的记录在 **30 天**后过期，读取或写入历史时自动清理。历史保留预算为 **50 条记录／50 MiB 序列化数据**；较早的已停止记录可能提前清理，以满足这些预算，正在采集的记录受到保护，不参与此类清理。这些预算不代表 IndexedDB 的实际磁盘占用量。单次采集的容量限制也可能更早省略或移除部分请求、正文及其他数据。
- 网站调试历史在任务结束或断开连接后仍会保留。用户可在历史页面删除已停止的记录；清除扩展存储或卸载扩展会删除本地历史。这些操作以及自动过期不会删除此前导出的文件，也不会删除 Agent 或网关已经收到的副本。
- 上传和下载字节由本地守护进程暂存在私有、按 session 隔离的目录中。下载暂存文件在复制到指定目标后删除；上传暂存文件保留到 session 结束，以便页面稍后提交表单时仍可读取附件。session 结束、连接断开或守护进程在崩溃后再次启动时，会清理剩余暂存文件。

- 操作审计独立于网站调试，默认关闭。开启后，所选守护进程会在 `BSK_HOME/audit`（默认用户目录下的 `.bsk/audit`）保存任务与操作元数据，包括时间、工具类型、网站来源、经过基础脱敏的元素名称、状态和错误码；操作审计不保存输入值、页面正文、截图、脚本或文件内容，这些排除项不适用于上述网站调试历史。已结束的任务保留 30 天，在服务加载、开启审计、创建任务或查询列表时清理。用户可在审计页导出或删除已结束的记录。导出的副本不参与自动清理。

- 远程端点和设备凭据单独保存在扩展来源的 IndexedDB 中，直到用户切回本地连接、清除扩展存储或卸载扩展。普通设置仅保存不含凭据的版本标记。服务端授权保留至撤销，过期授权不能连接；断开连接不会删除服务器已收到的结果和审计记录。

## 8. 用户控制

用户可随时：

- 在 `chrome://extensions` 中卸载本扩展，从而清除扩展存储；守护进程所在主机的审计文件与自行导出的副本需要另行删除。
- 通过快捷功能中的“网站调试”停止采集，或让 Agent 停止采集。进入其历史页面查看、导出记录或删除已停止的记录；无需连接守护进程也可使用历史页面。删除正在采集的记录前，需先停止采集。
- 在快捷功能中关闭操作审计，停止收集新的审计操作并保留已有审计记录；已记录任务仍会更新最终生命周期状态。此开关不会停止网站调试采集，也不会删除其历史。
- 关闭代理窗口，立即停止所有助手自动化操作。
- 开启借用前确认，并拒绝借用请求，使已有标签页保持不可访问。
- 关闭连接开关、切回本地连接或停止所选守护进程。
- 在服务器执行 `bsk daemon revoke DEVICE_ID` 撤销设备授权，或使用网关运营者提供的撤销功能。

## 9. 儿童隐私

本扩展是面向开发者的工具，并非面向 13 岁以下儿童。

## 10. 安全性

本地模式信任能够绑定所配置回环端口的进程。远程模式要求主动配对和加密传输，回环开发场景除外。内置服务端保存凭据哈希，校验连接，支持凭据轮换，并在授权撤销或过期后断开连接。第三方网关需要实现同一套授权生命周期与设备路由隔离。

远程读取和操作仅允许访问任务创建或明确借用的标签页；把用户标签页移入代理窗口本身不会授予权限。借用遵循浏览器用户控制的确认偏好。请仅配对有权操作您浏览器配置及已登录网站的可信服务器，保护好浏览器配置、服务端数据和 TLS 密钥。部署细节见[远程浏览器连接](../../docs/remote-extension-connection.md)。

网站调试会在保留数据前，对可识别的凭据请求头／响应头（如 Authorization、Cookie 和 Set-Cookie）、敏感 URL 参数、JSON／表单键名及常见凭据文本模式进行脱敏。页面观察中的凭据、支付和文件输入字段会被省略或脱敏。这种过滤不能保证任意请求／响应正文、控制台消息、页面文本或字段值均不含个人或机密信息。请将已保存及导出的调试数据视为可能包含敏感信息，分享前先检查，并删除不再需要的副本。采集、脱敏和保留限制详见[网站调试](../../docs/website-debugging.md)。

## 11. 开源与可审计性

BrowserSkill 是开源项目，任何人都可以通过阅读项目仓库中的源代码来核实本政策中的所有声明。本扩展不包含会隐藏网络调用的混淆或压缩代码路径。

## 12. 政策变更

如本政策发生重大变更，上方的"最后更新"日期会随之更新，新版本会随扩展一同发布。在更新发布之后继续使用本扩展，即视为接受修订后的政策。

## 13. 联系方式

如有隐私相关的问题或请求，请在 BrowserSkill 项目仓库中提交 issue。
